# Tokeru Fuuka to Shirousagi Chinese Patch Tools

本仓库当前保存汉化项目的三个源码目录：

- `game_patch`：补丁安装程序源码。
- `resource_tool`：游戏资源反编译、剧情表格、OCR 与补丁构建工具源码。
- `translate_tool`：多模型 Excel/TSV 翻译工具源码。

为了符合 GitHub 的单文件和仓库体积限制，没有提交游戏本体、XP3、内嵌
`patch.zip`、编译输出、OCR 模型、CUDA/Paddle 运行时、Node.js 依赖、翻译
缓存、工作表或本地 API Key。

各目录的具体说明见目录内的 `README.md`。
